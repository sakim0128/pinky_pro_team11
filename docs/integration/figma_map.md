# Figma 차선 레이어와 레이아웃

대시보드 1:2에서 확인한 새 카드 크기: Fleet Map 768×500, Camera 599×500,
카드 간격 25. 지도 내부 728×390. 웹은 이 비율로 반응형 배치합니다.

차선 원본: Figma zKykssBLh6s6aScPY2z2UZ / Vector 16:1412.
내보낸 SVG 바이트를 fleet-lanes.svg로 저장했습니다. 다시 그리거나 편집하지 않았습니다.
새 Figma API 요청은 Starter 한도로 실패하여 앞서 확보한 asset URL을 사용했습니다.

기존 확인 메타데이터:
- 전체 Rectangle 1: x=-3233, y=-1494, width=5957, height=3194
- Vector: x=-3205.5, y=-1311.5, width=5825.5, height=2934

전체 영역 안에서 x=27.5, y=182.5의 여백을 유지하며 같은 배율로 표시합니다.
카드에 맞춰 벡터만 늘리지 않습니다. 회색 바탕은 웹 표현용 스타일입니다.

`map5`는 별도 기본 레이어로 웹에 제공됩니다. 메타데이터는 236×128 셀, 0.01 m/cell,
origin `[-0.01, -0.01, 0]`입니다. `frame_id=map`이고 localized인 실제 상태만 map5의
좌표계로 변환해 표시합니다.

아직 Figma 도면과 map5 사이의 실제 기준점 정렬은 검증되지 않았습니다. 도면을 실제 ROS
위치에 대응하는 맵으로 주장하지 않으며 화면에 좌표 정렬 대기를 명시합니다. 예시 로봇/GOAL은
하드코딩하지 않습니다. Figma 레이어 위에 실제 로봇 오버레이를 표시하려면 기준점 대응 측정이
필요합니다.

웹 기본 map5 레이어에는 이 SVG를 map5 전체 경계로 정규화해 겹쳐 표시합니다. SVG 자체는
Figma의 전체 Rectangle 안에서 x=0.461642%, y=5.713839%, width=97.792513%,
height=91.859737%에 있던 값을 그대로 유지합니다. 이는 설계 정렬이며, 실기 기준점 확인 전에는
회전·이동 보정을 적용하지 않습니다.
