# Fleet Map 표시 자산

2026-09-30 기준 차선은 사용자가 제공한 `Vector (2).png`(5459×2905 RGBA)를 사용합니다.
흰 차선과 외곽선 없는 빨간 표시 3개가 포함된 투명 이미지입니다.
Figma 참고: https://www.figma.com/design/zKykssBLh6s6aScPY2z2UZ/Pinky-Fleet-Control?node-id=16-2

기존 `/fleet-lanes.svg` 경로를 유지하기 위해 SVG의 image 요소에 PNG 원본 바이트를
base64로 포함했습니다. PNG를 재인코딩하거나 차선을 다시 그리지 않았습니다.
SVG 주석에 원본 파일명과 SHA-256을 기록하며 테스트에서 원본 일치 여부를 확인합니다.
이 파일은 래스터 이미지를 담은 SVG 래퍼이며 순수 벡터 도형은 아닙니다.

지도 보드는 map5의 236×128 비율을 유지하며 카드의 너비와 높이 안에 맞춥니다.
차선은 보드 왼쪽 5%, 위쪽 8%, 너비 90%에 배치하며 높이는 원본 이미지 비율로 계산합니다.
이 여백은 제공된 도면의 시각적 배치에 맞춘 값입니다. 상태 문구는 지도 아래에 표시하여
차선을 가리지 않습니다. 배경은 #dedede이며 점유 장애물은 기존 map5 이미지입니다.

map5 메타데이터는 236×128 셀, 0.01 m/cell, origin [-0.01, -0.01, 0]입니다.
로봇 위치·공분산·목표점 좌표 변환은 기존 map5 기준을 사용합니다.
이 변경은 화면 표시 수정이며 Figma 도면과 실제 주행 기준점 사이의 물리적 보정을 뜻하지 않습니다.

검증: 390px, 900px, 1440px 브라우저 화면에서 지도와 차선의 경계 포함 여부 및
원본 비율 유지, 상태 문구가 지도 밖에 있는 것을 확인했습니다.
