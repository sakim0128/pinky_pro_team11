미션 배정 (시작 → 목적지)

도로망의 출발·도착 노드(endpoint) 중에서 로봇마다 고릅니다. 배정하면 경로가 새로 계산되고 출발은 하지 않습니다. 순서: 배정 → ③ 초기 위치 보내기 → 주행 시작.

—

같은 목적지·다른 로봇의 경로 위 목적지는 서버가 거절합니다(ASSIGN_CONFLICT).
